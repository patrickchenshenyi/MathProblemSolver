# 部署指南（阿里云 ECS）

> 用途：把已构建的 math problem solver（DSH + AIMO 插件）部署到阿里云 ECS，作为公开 demo。
> 版本：2026-09-22。以工坊（`deepseek-harness-aimo` + `~/.dsh-build`）实测结构为准。

---

## 0. 架构与前置说明

```
公网浏览器 ──HTTPS(443)──> Caddy ──> 127.0.0.1:3080 (dsh web, systemd 常驻)
                                          │
                                          ├─ Docker Engine ──> aimo-python-runtime 容器（模型代码沙箱）
                                          └─ api.deepseek.com（deepseek-v4-pro，凭据在 DSH_HOME）
```

三个关键事实（决定了下面的做法）：

1. **dsh web 只绑 `127.0.0.1`**（CLI 不支持 `--host 0.0.0.0`）→ 公网必须经 Caddy 反代，安全组**不要**开 3080。
2. **服务器用 Docker Engine，不是 Docker Desktop**（Docker Desktop 是 Mac/Windows GUI，不参与打包）。
3. **无登录鉴权**（按你的决定）。风险与缓解见 §11。

---

## 1. 本地准备（打包什么）

| 内容 | 传法 | 备注 |
|---|---|---|
| 代码：`deepseek-harness-aimo`（含 `packages/aimo/{python,verifier,code-runtime-docker}` 与 `packages/experimental/{agent-team,tool-agent-team}`） | git push 私有仓库，或 `tar czf dsh.tar.gz deepseek-harness-aimo` | `node_modules` **不带** |
| 沙箱镜像定义：`AIMO/MyProject/docker/{Dockerfile,bootstrap.py}` | 随代码或单独传 | 服务器上 `docker build` |
| 配置：credentials（API key）、profile patch | **单独 scp，不进 git** | 含秘密 |
| 新 API key（短 expire） | 部署前创建 | 见 §11 |

> `MyProject/eval/`（基线题集）**demo 不需要**——它是评测用的，不是运行时依赖。verifier 的约束谓词已在 `packages/aimo/verifier/constraints/*.py`，随代码走。

## 2. 创建 ECS + 安全组

- 规格：**4c8g 起步**（DSH 是 Node 常驻 + 并发 Docker 子进程；2c4g 勉强，内存吃紧）。
- 系统：Ubuntu 22.04 LTS。
- 安全组入方向：**22**（SSH，建议仅限你的 IP）、**80**、**443**。**不要开 3080**（只绑本地）。

---

## 3. 装环境（Ubuntu 22.04）

```sh
# Node 22 LTS
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# pnpm
npm install -g pnpm

# Docker Engine
curl -fsSL https://get.docker.com | sudo sh
sudo systemctl enable --now docker

# Caddy
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install -y caddy
```

## 5. 构建沙箱镜像

先把 `MyProject/docker/`（`Dockerfile` + `bootstrap.py`）scp 到服务器，例如 `/opt/aimo-docker/`：

```sh
docker build -t aimo-python-runtime:latest /opt/aimo-docker   # 指向含 Dockerfile + bootstrap.py 的目录
# 验证
docker run --rm aimo-python-runtime:latest python3 -c 'import sympy, numpy, mpmath; print("ok")'
```

> 镜像名必须与插件默认一致（`aimo-python-runtime:latest`）；要改请在 patch 里给 `aimo-code-runtime-docker` 配 `image`。

## 6. 配置 DSH_HOME + 凭据 + patch + 插件解析

```sh
export DSH_HOME=/opt/dsh-home
mkdir -p $DSH_HOME/profiles/node_modules/@deepseek-ai
```

**凭据**：把新 key 写进 `/opt/dsh-home/.credentials.yaml`（结构照搬工坊 `~/.dsh-build/.credentials.yaml`，只替换 key 值）。

**profile patch**：写 `/opt/dsh-home/profiles/web/cordis.patch.yml`（web profile 首次启动会自动生成，先手动建好即可）：

```yaml
# 关闭 base 的 worker-thread 代码运行时，换成容器后端（ctx.codeRuntime 是单例）
- id: code-runtime
  disabled: true

- insert:
    - id: agent-team
      name: '@deepseek-ai/dsh-experimental-agent-team'

- insert:
    - id: tool-agent-team
      name: '@deepseek-ai/dsh-experimental-tool-agent-team'

- insert:
    - id: aimo-code-runtime-docker
      name: '@deepseek-ai/dsh-aimo-code-runtime-docker'

- insert:
    - id: aimo-python
      name: '@deepseek-ai/dsh-aimo-python'

- insert:
    - id: aimo-verifier
      name: '@deepseek-ai/dsh-aimo-verifier'
```

**插件解析（symlink）**：裸插件名通过 `$DSH_HOME/profiles/node_modules` 解析。首次 `dsh` 启动会自动 heal 掉 app/bundle 闭包里的 ~200 个符号链接，但 **5 个自定义包不在闭包内，必须手动建**：

```sh
cd $DSH_HOME/profiles/node_modules/@deepseek-ai
ln -s /opt/dsh/packages/aimo/verifier             dsh-aimo-verifier
ln -s /opt/dsh/packages/aimo/python               dsh-aimo-python
ln -s /opt/dsh/packages/aimo/code-runtime-docker  dsh-aimo-code-runtime-docker
ln -s /opt/dsh/packages/experimental/agent-team       dsh-experimental-agent-team
ln -s /opt/dsh/packages/experimental/tool-agent-team  dsh-experimental-tool-agent-team
```

## 7. 启动 + systemd 常驻

```sh
# 运行用户要能执行 docker（否则 code-runtime-docker 会失败）
sudo usermod -aG docker $USER && newgrp docker

sudo tee /etc/systemd/system/dsh-aimo.service >/dev/null <<'EOF'
[Unit]
Description=DSH AIMO Math Solver
After=network.target docker.service

[Service]
Type=simple
WorkingDirectory=/opt/dsh
Environment=DSH_HOME=/opt/dsh-home
ExecStart=/usr/local/bin/pnpm dsh web --port 3080 --no-open --trusted-host demo.yourdomain.com
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now dsh-aimo
```

> `--trusted-host` 换成你的真实域名，否则 `/api` 的 browser-trust 校验会拒掉经域名进来的请求。

## 8. Caddy 反代 + HTTPS

`/etc/caddy/Caddyfile`：

```
demo.yourdomain.com {
    reverse_proxy 127.0.0.1:3080
}
```

```sh
sudo systemctl reload caddy   # Caddy 自动申请/续期 HTTPS 证书
```

## 9. 验证 checklist

```sh
# 1) 组合正确（5 个插件 + code-runtime 已禁用 + agent-team 已挂）
sudo -E DSH_HOME=/opt/dsh-home pnpm dsh --profile web --dump-config 2>/dev/null | grep -E "aimo|agent-team|code-runtime" 

# 2) 本地进程起得来
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:3080/    # 期望 200

# 3) 公网经 Caddy 可达
curl -s -o /dev/null -w "%{http_code}\n" https://demo.yourdomain.com/   # 期望 200

# 4) 沙箱可用（模型代码能进容器跑）
docker ps -a | grep aimo-python-runtime   # 解一题后应有容器启动记录

# 5) 端到端：在 Web UI 里发一道 AIME 题，确认模型调用 run_code/verify_answer、给出 boxed 答案
```

## 10. 更新 / 回滚 / 卸载

- **更新**：`git pull`（或重新 tar）→ `pnpm install && pnpm run build` → 若插件/symlink 变了重新建 → `systemctl restart dsh-aimo`。
- **回滚**：`git checkout <旧提交>` → build → restart。
- **卸载**：`systemctl disable --now dsh-aimo`；`rm -rf /opt/dsh /opt/dsh-home`；`docker image rm aimo-python-runtime`；删 Caddy 域名段。

---

## 11. 安全说明（无 auth，已按你的决定）

你已做的缓解（预付费额度上限 + 专用 key + 短 expire）是有效的，但要清楚边界：

1. **拿到 URL 的任何人**，在 key 过期前都能驱动 agent（相当于能花你的额度、看到会话内容）。开放时间越短、expire 越快，风险越小。
2. 两个**零成本**的额外加固，建议顺手做：
   - 安全组 22 端口只对你的 IP 开放（ssh 不被扫）；
   - 演示结束后**立刻在 DeepSeek 控制台撤销/删除该 key**（比等 expire 更干净）。
3. 若哪天要长期公开，再加 Caddy `basic_auth` 一行即可（`basicauth { user <hash> }`），不必改 DSH 任何代码。
